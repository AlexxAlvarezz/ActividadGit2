PROPOSITO DEL PROYECTO

1. Parte de GitHub.
   
Crear un repositorio en Github para el proyecto.
Crear tres ramas adicionales desde la rama main.
- matriz-inical: Para generar y mostrar la matriz de números aleatorios
- busqueda-numero: Para implementar la búsqueda de un número.
- suma-matriz: Para calcular y mostrar la suma de los números.


2.Parte de creación de la actividad.

- Desarrollar una aplicación en Java que cumpla las siguientes funciones:
- Crear una matriz de 5x5 de números aleatorios entre 1 y 100.
- Mostrar la matriz por consola.
- Permitir al usuario buscar un número en la matriz. Si el número está presente,    mostrar su posición (fila y columna). Si no, informar que no exite.
- Calcular i mostrar la suma de todos los números de la matroz.
